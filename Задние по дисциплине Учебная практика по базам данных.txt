Задние по дисциплине «Учебная практика по базам данных»
Разработать приложение баз данных для ведения базы данных задач по
программированию с автоматической проверкой.
Имеется набор задач по программированию, которые можно использовать
для формирования контестов для платформ Yandex Contest, Codeforces и др.
Требуется создать приложение, интерфейс которого позволит добавлять,
удалять и изменять информацию о задачах, а также фильтровать список
задач и формировать отчеты.
Для каждой задачи известно:
- название на русском языке
- краткое условие (многострочный текст)
- краткая идея решения (многострочный текст)
- ссылка c polygon.codeforces.com (URL-адрес), с помощью которой задачу
можно залить в систему с автоматической проверкой решений (Yandex
Contest, Codeforces и др.)
- в каких контестах использовалась (для контестов сделать отдельный
справочник)
- подготовлена ли задача для заливки на Codeforces? (логическое поле,
автозаполнение True при заполнении поля «ссылка c polygon.codeforces.com»)
- подготовлена ли задача для заливки на Yandex Contest? (логическое поле)
- сложность задачи (экспертная оценка – целое число от 1 до 10)
- теги задачи (какие темы затрагивает, для тегов сделать отдельный
справочник)
- примечание (многострочное поле)
Для контестов известно:
- название контеста на русском языке
- год, когда был создан контест
Для тегов задач известно:
- название тега
Каждая задача могла использоваться в нескольких контестах, при этом
каждый контест состоит из одной или нескольких задач.
Каждая задача может быть помечена несколькими тегами, и при этом
одному и тому же тегу может соответствовать несколько задач.
Важно сделать возможной фильтрацию списка задач по сложности (от одного
заданного значения до другого) с одновременным указанием одного или
нескольких тегов, которым должны соответствовать задачи.
Требуется сделать два уровня доступа к приложению:
- администратор должен владеть всеми функциями, он должен ввести логин
и пароль при входе в систему;
- пользователь работает без авторизации и имеет доступ только к просмотру
информации в базе данных, ее фильтрации и формированию отчетов.
СУБД для хранения базы данных, язык программирования, фреймворк для
реализации приложения выбираете самостоятельно. Особых ограничений
нет. Единственно, ваше приложение и база данных должны без особого труда
развертываться на другом компьютере, т.е. не должно в ходе развертывания
и своей работы требоваться установка ПО, которое является платным,
недоступно без VPN и т.п.
Сдать нужно работающее приложение и отчет, в котором подробно описать
архитектуру приложения, способ развертывания и продемонстрировать
основные функции, используя скриншоты и видеоматериалы (при
необходимости).
Минимально должно быть настольное приложение, за создание Webприложения, в случае удачной реализации, возможны дополнительные
баллы.
